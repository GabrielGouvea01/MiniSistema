# Mini sistema para gerenciamento de alunos.

## Objetivo:
### Requisitos funcionais:

1. Adicionar alunos:
-Recebar Nome, Turma, Nascimento, Ativo.

2. Excluir aluno:
-Excluir um aluno específico pelo ID.

3. Listar alunos:
-Consultar um aluno específico pelo ID.

4. Listar todos os alunos:
-Cria um relatório com todos os alunos cadastrados.

5. Atualizar aluno:
-Atualiza cadastro apartir do ID.
